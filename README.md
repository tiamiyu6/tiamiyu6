### IspFlow — [ispflow.dev](https://ispflow.dev)

A multi-tenant SaaS platform for running an ISP: network, billing, and payments in one place instead of spreadsheets and disconnected tools.

- **Isolated tenants** — each ISP gets its own branded captive portal (`yourisp.ispflow.dev`); no tenant ever sees another's subscribers, routers, or revenue
- **MikroTik router integration** over an encrypted tunnel — no port forwarding or static IP required to link a router
- **Subscribers, vouchers, plans, and payments** managed from one dashboard, with a live revenue and traffic overview
- **Automation bots** running in the background: Security & Oversight, Finance & Funds, Campaign & Study, and a Super-bot that reads the other three and surfaces what actually needs a decision
- Self-serve onboarding (email + optional WhatsApp verification), a working live demo with sample data, 14-day free trial

### Longlife Hospital — care system

A role-based operations system for a Lagos hospital: nurses issue patient cards, doctors write prescriptions, pharmacists dispense and manage stock, and admins see finance across the whole facility. Includes a public cost-estimate tool patients use to price out services before a visit, low-stock/expiry alerts, and a full audit trail.

### Website Vulnerability Scanner

A passive, non-destructive security scanner — checks TLS configuration, security headers, cookie flags, CORS setup, and common exposed files, then explains **how an attacker would use each finding** and **exactly how to fix it**, in plain English. Ships as both a CLI (`node cli.js https://example.com`) and a hosted dashboard with a shareable PDF report.
